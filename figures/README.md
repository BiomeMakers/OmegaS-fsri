# Figures

Generated by `make_figures.py`. All three are computed rather than drawn: the
graphs are constructed in code and every quantity in a label is evaluated from
the adjacency matrix.

```bash
python figures/make_figures.py
```

- `figure1_monopoly` : a distributed network beside a structural monopoly at
  matched edge count, with per-node triangle counts. Shows what the index
  responds to.
- `figure2_cospectral` : the counterexample of Proposition 4. The pair is
  located by exhaustive search inside the script rather than hard-coded, so the
  figure is evidence for the claim in the text rather than an illustration of
  it: identical spectrum, identical Tr(A^3),
  different diag(A^3).
- `figure3_signed` : balanced against frustrated triangles, and what taking |A|
  destroys.
