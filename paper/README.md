# Paper

The paper lives here in two forms and they are generated from the same source:

- `fsri_preprint.tex` : LaTeX source, identical byte for byte to the copy in
  the arXiv submission folder.
- `fsri_preprint.pdf` : compiled output, 29 pages.

## Note on the removed Markdown rendering

Earlier revisions of this repository also carried `fsri_preprint.md`, an
abbreviated Markdown rendering of the paper. It was generated from a much
older draft and was never regenerated, so it still stated results that the
paper itself has since withdrawn: a four-orders-of-magnitude separation in
Proposition 2 that turned out to be an artefact of a numerical floor, and a
compression figure for the applied companion work that has since been
re-attributed to the group-lasso term it was combined with.

Rather than publish a stale second version of the same document, it has been
removed. The `.tex` and the `.pdf` are the paper.
